# 判断記録（docs/decisions/）

AI 開発セッション中の質問・人間の回答・選定理由・会話参照を残す場所。
手順は `.agents/skills/own-the-why/SKILL.md` を参照。

## ファイル名

`YYYY-MM-DD-<slug>.md` とし、ファイル名をそのまま判断IDとして参照する。
`docs/DECISIONS.md` の D-XXX（技術選定の記録）とは別系統で、番号を混同しない。

## 記録の型

- 日付・セッション参照（実在するリンクのみ。未取得は「未取得」と書く）
- 質問: 実際に聞いた文・選択肢
- 回答: 本人の文を正確に引用し、AI の要約と区別する
- 選定理由: 本人の回答のみ。未回答は「未回答」と残し、推測で補完しない。未選択の候補に拒否理由を推測しない
- 使った質問手段・深さ（短い確認のみ / dig 相当 / grilling 相当。スキル未導入で同等手順に代替した場合はその旨も）
- セッション終了時に追記: 結果・検証・commit・PR
