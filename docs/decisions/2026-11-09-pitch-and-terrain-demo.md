## 本人の理由

- 選択肢を選んだ項目は、その選択肢の説明を本人が採用した理由として扱う（Q1の回答）。
- 1経路の実計算（Q4）と Routes API（Q13）は、AI推奨と異なる本人の選択。選択肢以外の理由の追記はない。
- 動画の要件（Q21）は本人が運営の案内として回答した内容。公式原本との照合はしていない。

## AIが示した設計上の理由（本人の理由と区別）

- 経路を保存しない：Google Maps Platform の規約は Routes API の緯度経度の一時保存を30日までに限り、経路の形の保存は明示的に許可していない（[Routes API の規約](https://developers.google.com/maps/documentation/routes/policies)、[サービス固有規約](https://cloud.google.com/maps-platform/terms/maps-service-terms)）。標高と日陰は公開データから地区全体を事前計算し、表示時に取得した経路を重ねて集計する。
- 費用：Compute Routes Essentials は月1万回まで無料（[料金一覧](https://developers.google.com/maps/billing-and-pricing/pricing)）。デモの利用量はこの範囲を想定。徒歩の代替経路を使う場合の料金区分は未確認。

## 範囲外・未確認

- 現地精度、段差・幅員などの通行可否は検証も保証もしない。
- 対象地区、データの版・欠損率、計算結果は実装担当の報告後に記録する。
- デプロイ（PR #12・#16）の反映は別作業。
