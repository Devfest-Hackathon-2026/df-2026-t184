## AI の実装判断

作業を 3 つの PR に分ける。

1. 地図の高さを境目のドラッグで変える（Q2）
2. 見つからない寄り道地点を「?」ピンとリストの注記で示す。Q6 で選び直しは対象外と決まったため、仮の位置であることを正直に出す。地点名は目的地名を付け足さず、目的地のまわり（約 3km 四方）を優先して検索する。目的地名を付け足すと `partial_match` になり、実在する地点まで捨てていた可能性が高いため（推測。実際の応答は未確認）。仮の位置の前後の区間には、坂・日陰のタグを出さない
3. 出発地・目的地を Places 自動補完で選び、出発地も Gemini に渡す（Q4・Q5）。有料 API の追加なので、AGENTS.md の要相談 PR にする
