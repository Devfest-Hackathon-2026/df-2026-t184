# 入力画面の所要時間に「固定の見本値」と表示する

- 日付: 2026-11-10
- 状態: AI判断・PM確認待ち（superloop の worker が F01 の差し戻し対応で決めた）

## 背景（コードから観測した事実）

- `/walk` の入力画面の付箋（`src/features/walk/components/EtaNote.tsx`）は「約N分 / 最短よりM分長い寄り道」を出す
- 値は `src/features/walk/flow.ts` の `SHORTEST_MIN` と `EXTRA_BY_BUDGET` の固定値で、経路から計算していない
- 評価役が `docs/RULES.md` の失格条件「固定値を本物の結果のように見せている（画面に区別の表示がない）」に当たると指摘した

## 決めたこと

- 付箋に「目安（固定の見本値。実際の経路からは計算していません）」を1行足す。値と計算は変えない
- 候補: (A) 区別の表示を足す（採用）、(B) 付箋を消す、(C) Routes API の結果から計算する
- 捨てた理由: B は既存の画面構成を変える。C は機能の追加で、F01（機能を追加しない）の範囲を超える

## 残っていること

- 思い出カードの「+M分」（`MemoryCard`）も同じ固定値から出ている。選んだ寄り道時間の表示として扱い、今回は変えていない
