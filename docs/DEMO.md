## ローカルでの確認手順

```sh
npm ci
cp .env.example .env.local   # キーなしのままでよい
npm run dev                  # http://localhost:3000
```

- `.env.local` をキーなし（`.env.example` のコピー）にすると: 地図キーがないので地図は手描きのイメージ図（注記つき）、`/terrain` は Routes API が呼べず「直線で評価しています」の警告つき。`/api/quests` の成否は端末の ADC の有無で変わる（`src/lib/vertex-server.ts` が `applicationDefault()` を使うため、`.env.local` の中身では ADC は無効にならない）:
  - ADC 未設定の端末 → Vertex AI の呼び出しが失敗し、`/walk` は原因つきの知らせ＋見本クエストに切り替わる
  - **ADC 済み（`gcloud auth application-default login` 実行済み）の端末 → キーなしでも実際の Gemini が呼ばれ、有料の呼び出しになる**。見本への切り替えを確かめたいときは `.env.local` の `VERTEX_PROJECT_ID` を空にする（プロジェクトが決まらず Config 失敗 → 見本に切り替わる）
  - どちらでも流れ全体は止まらない
- 本物の Gemini を試すときだけ: `gcloud auth application-default login`（`VERTEX_PROJECT_ID=df-2026-t184-prod` は `.env.example` 入り。呼び出しは有料）
- 本物の地図を試すときだけ: `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` に stg のキー（Secret Manager `STG_GOOGLE_MAPS_API_KEY`、localhost:3000 許可済み）を入れる
- チェック: `npm run lint` / `npm test` / `npx next typegen && npx tsc --noEmit` / `npm run build`（`docs/RUNBOOK.md`）

## stg での確認手順

URL: `https://yorimichi-stg--df-2026-t184-prod.asia-east1.hosted.app`（`docs/environments.md`）

1. `/` を開き `/walk` に入る → 上の「デモで見せる流れ」をそのまま操作する
2. stg では実行用サービスアカウント（`roles/aiplatform.user`）で Vertex AI が呼べるため、Gemini が成功すればルート画面に「Gemini（AI）が作ったクエストです」と出る。失敗した場合は原因つきの知らせに変わる（どちらも正常）
3. `/terrain` では Routes API で2経路を取り、推定値表が出る。キー制限で経路が取れない場合は「直線で評価しています」の警告
4. 回数制限の確認（任意）: 同じ端末から `/api/quests` を短時間に 11 回以上呼ぶと 429 と `Retry-After` が返り、画面は見本＋原因の知らせに切り替わる（2026-11-10 に stg で実測済み。記録は `evidence/F04/stg-curl.txt`・`docs/decisions/2026-11-10-f04-rate-limit.md`）

stg の実動確認の経緯: 2026-11-10 にデプロイ・ロールアウト・smoke check・`/api/quests` の Vertex AI 呼び出し成功まで確認済み（`docs/decisions/2026-11-10-stg-tag-deploy-verification.md`、`docs/decisions/2026-11-10-vertex-gemini.md`）。

**注意（2026-11-10 12時台に curl で観測）**: stg は共用で「最後にデプロイされた内容」が表示される。
現在の stg は F08/F09 取り込み前のビルドで、`/` → `/walk` は 307 で 200、`/terrain` は 404 を返す。
`/terrain` を stg で見せるには、統合ブランチの main へのマージ後に stg へのデプロイ（PR の CI/CD、または `firebase deploy --only apphosting:yorimichi-stg`）が必要。
デモ当日までに stg を最新にするか、ローカル（`npm run dev`）で `/terrain` を見せるかは PM 判断。

## デモ中に起きうることと対処

| 状況 | 画面の動き | 対処 |
|---|---|---|
| Gemini が失敗・時間切れ | ルート画面に原因つきの知らせ＋見本クエスト | そのまま続行（見本で流れは最後まで通る） |
| 回数制限（429） | 「短い時間にAIを呼びすぎた」の知らせ＋見本クエスト | 1分ほど待つと回復。見本で続行も可 |
| 地図キーなし・読み込み失敗 | 手描きのイメージ図＋注記 | そのまま続行 |
| `/terrain` で経路が取れない | 「直線で評価しています」の警告＋推定値表 | 推定値は出るので表と方法論を見せる |
| ページ再読み込み | ポイント・記録が消える | 保存しない設計である旨を説明（画面にも注記あり） |
