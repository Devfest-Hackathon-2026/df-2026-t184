## 試し方
1. `npm run dev` → `http://localhost:3000`
2. 目的地・気分を選んで「寄り道ルートを作る」
3. 保存すれば、次の生成から新しい指示になる

※ `GEMINI_API_KEY` の設定はクマタニさんに頼む。キーは Discord や Git に貼らない。
