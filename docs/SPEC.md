# 寄り道MAP 仕様（superloop 用）

承認: PM 2026-11-10（夜間ループのブリーフ `docs/superloop-brief.md` を元に作成）。基準: `origin/main` = `3d64fc0`。

## 誰の・どんな課題か

`docs/REQUIREMENTS.md` の課題仮説を使う（未検証の仮説で、調査による裏付けはまだない）。

- 日常の徒歩移動: 寄り道する時間はあるのに行き先を思いつかず、いつも最短ルートで着いてしまう（根拠: 未記入: 要調査）
- 観光地での滞在: 目的地の合間の空き時間を、自分好みの過ごし方に使えていない（根拠: 未記入: 要調査）
- 坂・日陰: 観光客や移動に配慮が要る人も、坂と日陰の推定値を見てルートを選べるようにする（`docs/ARCHITECTURE-POLICY.md` の合意方針。推定値で現地未検証）

## デモシナリオ（これが通れば完成）

1. `/` を開くと `/walk` の体験に入る
2. 行き先・気分・寄り道してよい時間を入れる → 探索の演出 → Gemini が作った（失敗したら見本だと明示した）3地点のクエストと地図上のルート
3. 地点ごとに「見つけた」・写真枠・ひとことメモで記録 → ポイントと称号が付く
4. 3地点を終えると思い出カード → フィードで他の人のカード（見本と明示）
5. ルート画面から、上野〜谷中の固定デモ経路で最短ルートと寄り道ルートの坂・日陰（推定値・不明区間つき）を比べる
6. AI の失敗・時間切れ・回数制限・地図キーなしでも、上の流れが止まらない
